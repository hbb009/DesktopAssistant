# 桌面助手 Desktop Assistant

## 关于

注意：从 **v9.10** 起，本项目转为**闭源维护**。

- 本仓库中的历史提交仅作旧版源码归档，**不代表开放许可或欢迎外部贡献**。
- **v9.10 及之后**的正式交付物为编译程序（.exe 及配套运行目录），通过本仓库 **Releases** 发布与更新。
- 请勿将本仓库内容用于再分发、二次上架或商业倒卖；使用权以作者发布说明与授权范围为准。
- 问题反馈、使用交流可通过作者在 Release / 说明中公布的联系方式进行。

> 闭源 ≠ 停更：功能仍会迭代，只是源码不再作为公开交付形态。
