# 按钮样式标准（kind="std"）

- **名称**：标准按钮，`QPushButton[kind="std"]`，规则在 `styles/style_all.py` 的 `build_std_button_qss()`（亮/暗两套，随全站 QSS 挂载）。
- **用法**：`from styles.style_all import apply_std_button`，然后 `btn = apply_std_button(QPushButton("文字"))`（或 `btn.setProperty("kind", "std")`）。
- **外观**：以像素画板 · 画板页「批量导入」为准：高 22（含边框）、内边距 1px 4px、字 12px 加粗 600、圆角 7、半透明底细描边，悬停/按下加亮、禁用变淡。
- **强调色**：需要蓝底等强调色时，只在本按钮上叠本地样式改底色/字色，高度仍由标准规则管。
- **例外**：纯图标按钮、可勾选的选项按钮、对话框默认键保持各自样式。
- **规则：新建按钮一律用它。**
