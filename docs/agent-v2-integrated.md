# 新版 Agent 使用说明

重启程序，进入「本地对话 → Agent」。界面现已改为自然语言聊天，操作方式见 [对话式 Agent](agent-chat.md)。模型与服务地址沿用「配置」页的 Ollama 设置；本版工作流使用本地 Ollama。以下是后台工作流能力与文件说明。

## 五类任务

1. 网站助手：每行一个网址，支持网页正文、同章分页，以及小说目录展开；网页先缓存再保存。
2. 文档处理：TXT、Markdown、DOCX、PDF；摘要、改写、校对、翻译、提取、比较、搜索、统计、替换、合并、拆分、转换、改名副本、按格式分类、查重、复制和移动。PDF扫描页调用已有 PaddleOCR-VL，依赖和模型缺失时会明确报错。转换生成文字版文档，不承诺保留原排版。
3. 作者风格 Skill：添加全部章节（支持拖动排序），逐段分析、分级归纳，输出 SKILL.md、风格规则、场景规范、异情境示范、评估清单和材料覆盖索引。选择产物中的 author-style 目录即可用于写作。
4. 小说大纲：新建、修改、续篇；选择已有材料并说明要求，设置起始章号和章数，输出总纲、人物设定、章节细纲及检查说明。
5. 小说写作：新写、续写、修改、重写；加载 Skill 目录和已有大纲/正文。逐场景生成、检查、修订，章稿显示在聊天中；明确回复“确认本章”才能成为正式章节并进入下一章。也可直接说出意见重写本章。

## 文件与恢复

- 成果：所选工作目录 / Agent成果 / 任务编号。
- 完整任务：程序目录 / userdata / agent_tasks / 任务编号。
- inputs 保存原始快照；steps 保存每步请求、原始响应、校验与提交记录；logs 保存事件；state.json 保存界面状态；approvals 保存明确确认记录。
- 暂停、关闭或进程中断后，从「历史任务」打开旧任务，在聊天里说“继续”。已校验提交的步骤复用，未完成步骤重做。
- 修改输入文件后请新建任务。手动修改成果会阻止覆盖；先另存，避免覆盖自己的修改。
- 每次只运行一个任务。8192 为默认固定窗口，冷启动最多等待300秒；不会偷偷提升上下文。数量较多时运行时间随材料与生成量增长。
- 移动会先显示详细源/目标清单，用户确认后复制、校验，再移除源文件。其他文档编辑默认输出副本。

## 验证边界

自动化测试覆盖80份材料、五类工作流、真实本地HTTP抓取、文档读取、OCR分支、取消、进程中断恢复以及Qt按钮操作；真实模型验收使用小型合成材料。80章全量真实推理时间和成稿质量仍取决于素材与本地模型能力。扫描PDF的实际识别效果取决于现有OCR组件与页面质量。
