# model/ · 外置开源模型（勿提交）

本目录模型均为开源权重/源码，体积大，不进 Git。

下载：

```bat
2安装-模型.bat
```

或：

```bat
python tools\download_models.py
```

| PaddleOCR-VL-1.6 | 截图 OCR | 1.9GB |

| faster-whisper-large-v3 | 语音转写（更准） | 2.9GB |
| Fun-CosyVoice3-0.5B | 语音克隆 | 9GB |
